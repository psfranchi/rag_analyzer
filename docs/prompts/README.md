# Prompts for starting a specialized analyzer

These are plain-text briefs for **any** coding agent or chat LLM. Fill the `YOUR_…` blanks, then paste the fenced block.

This template stays **tool-agnostic**: no vendor agent folders, rules files, or IDE plugins are required.

| Prompt | Use when |
|--------|----------|
| [`START_NEW_DOMAIN.md`](START_NEW_DOMAIN.md) | Add a domain (e.g. `laws`) inside this template |
| [`START_NEW_PROJECT.md`](START_NEW_PROJECT.md) | Turn a clone into a single-topic product |
| [`REFINE_DOMAIN.md`](REFINE_DOMAIN.md) | Tighten labels, sources, or prompts after a first draft |

Also point the agent at [`AI_CONTEXT.md`](../AI_CONTEXT.md) so it respects platform boundaries.
